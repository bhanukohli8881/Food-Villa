# Food Villa

A restaurant discovery and ordering frontend built with React. Browse restaurants, view restaurant menus, and manage items in the cart.

## Requirements

- Node.js and npm

## Getting started

Install dependencies and start the Parcel development server:

```bash
npm install
npm run dev
```

Parcel will print the local URL in the terminal.

## Available scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build

## Application routes

- `/` — restaurant listings
- `/about` — about page
- `/contact` — contact page
- `/cart` — shopping cart
- `/restaurant/:resId` — restaurant menu

## Tech stack

- React and React Router
- Redux Toolkit and React Redux for cart state
- Tailwind CSS
- Parcel
